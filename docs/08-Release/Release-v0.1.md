# 1. 版本定位

JiuWei CRM v0.1 是项目的第一个可运行版本（MVP）。

本版本目标不是构建完整 ERP，而是交付一套能够支持招生老师真实工作的轻量级 CRM。

核心目标：

* 建立统一招生线索管理平台
* 替代 Excel 管理客户
* 建立咨询与跟进闭环
* 为后续 AI CRM 建立基础架构

# 7. 已知限制

v0.1 存在以下限制：

* SQLite 不适用于高并发场景。
* 单机部署，不支持多实例。
* 不支持 HTTPS。
* 不支持域名访问。
* 不支持移动端适配。
* AI 能力仅支持单一模型增强。
* 不支持企业微信、微信公众号等第三方平台集成。

上述限制将在后续版本逐步完善。
