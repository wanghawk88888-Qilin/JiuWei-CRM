# JiuWei CRM 产品需求文档（PRD）

**版本：** v0.1 MVP
**状态：** Draft
**更新时间：** 2026-07-02

---

# 1. 产品概述

## 1.1 产品名称

JiuWei CRM

## 1.2 产品定位

JiuWei CRM 是一套面向成人 AI 职业教育机构的轻量级招生 CRM 系统。

产品聚焦招生业务全流程管理，不以传统 ERP 为目标，而是围绕招生团队的日常工作，提供简单、高效、易上手的客户管理能力。

产品设计坚持 MVP 优先，优先解决真实业务问题，并为未来 AI 能力接入预留架构。

---

# 2. 产品目标

MVP 阶段重点实现以下目标：

* 建立统一的招生线索管理平台。
* 统一管理客户基础信息。
* 建立咨询与跟进记录。
* 管理线索生命周期。
* 为报名、开班、学习、就业模块预留数据基础。

系统成功标准不是功能数量，而是招生老师能够在真实业务中稳定使用，并逐步替代 Excel 和碎片化记录方式。

---

# 3. 用户角色

MVP 仅包含三个角色。

| 角色    | 职责                 |
| ----- | ------------------ |
| 超级管理员 | 系统配置、用户管理、查看全部数据   |
| 招生主管  | 分配线索、查看团队数据、监督跟进   |
| 招生老师  | 管理本人负责线索、咨询记录和报名信息 |

后续版本再增加教务、就业、财务等角色。

---

# 4. 核心业务流程

整个系统围绕以下业务流程展开：

```text
线索
↓

咨询

↓

跟进

↓

报名

↓

开班

↓

学习

↓

就业
```

v0.1 聚焦实现：

线索 → 咨询 → 跟进

---

# 5. MVP 功能范围

## 包含（In Scope）

* 线索管理
* 客户基础信息
* 咨询记录
* 跟进记录
* 状态管理
* 简历上传
* 简历基础字段提取

## 不包含（Out of Scope）

* 财务管理
* 教务管理
* 就业管理
* OA审批
* 企业ERP功能
* 多校区管理

---

# 6. 线索来源

v0.1 支持以下线索创建方式：

* 手工录入
* Word 简历上传
* PDF 简历上传

未来版本将支持：

* Excel 导入
* 企业微信
* 官网表单
* 招聘网站
* 第三方渠道

---

# 7. AI 能力（v0.1）

v0.1 支持简历上传与基础字段提取。

系统优先通过规则提取手机号、邮箱等确定性字段；单一大模型作为可选增强能力，用于复杂字段识别与候选人画像。

若大模型不可用，不影响线索创建流程。

v0.1 阶段仅接入一个默认大模型，不支持多模型切换、模型路由或模型效果评估。

---

# 8. 产品原则

1. MVP 优先。
2. 围绕招生流程设计。
3. 招生老师一天即可上手。
4. 默认支持中文。
5. 技术栈统一（Next.js + React + Tailwind CSS + FastAPI + SQLite）。
6. 桌面端优先。
7. 所有设计均考虑未来 AI 能力接入。
8. 所有需求必须经过 PRD → 原型 → 数据库 → API → 开发 → 测试 → 部署 → 版本迭代。
9. 所有新增需求默认进入 Product Backlog，仅阻塞当前 MVP、Bug 修复或业务强制需求允许进入当前版本。

---

# 9. MVP 验收标准

满足以下条件即视为 v0.1 达成目标：

* 可创建招生线索。
* 可维护客户基础信息。
* 可记录咨询内容。
* 可记录跟进历史。
* 可管理线索状态。
* 支持 Word/PDF 简历上传。
* 支持基础字段自动提取。
* AI 服务不可用时，不影响线索正常创建。
