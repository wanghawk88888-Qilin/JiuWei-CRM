# JiuWei CRM 产品 Backlog

**版本：** v0.1
**状态：** Final
**更新时间：** 2026-07-02

---

# 1. 文档目的

Backlog 用于记录当前版本未开发、但已确认具有产品价值的需求。

所有新增需求默认进入 Backlog，不直接进入当前开发版本。

只有满足以下条件，才允许进入当前版本：

* P0 Bug
* 安全问题
* 阻塞核心业务流程
* 产品负责人确认升级版本范围

否则统一进入 Backlog。

# 11. 产品原则（长期）

整个项目长期坚持以下原则：

1. MVP 优先。
2. 文档驱动开发。
3. 页面稳定，能力扩展。
4. AI 增强，而非 AI 依赖。
5. 数据优先于界面。
6. 保持轻量，不 ERP 化。
7. 所有需求先进入 Backlog，再决定版本。
8. 保持 GitHub + Docker Compose + ECS 的统一部署方式。
