## 1. 功能说明

### 1.1 今日待跟进增强

Dashboard 首页「今日待跟进」卡片升级：

**覆盖范围扩展：**
- **已逾期**：next_followup_at < 今天（红色标记）
- **今天到期**：next_followup_at = 今天（黄色"今天"标记）
- **即将跟进**：next_followup_at 在未来 3 天内（灰色样式）

**新增展示字段：**
| 字段 | 说明 |
|---|---|
| 意向课程 | 客户意向课程名称（JOIN courses 表） |
| 最近跟进 | 最近一次跟进记录内容摘要（截取前 50 字） |
| 优先级标记 | overdue / today / upcoming 分类 + 彩色 Badge |

**排序规则：**
1. 已逾期 (按 next_followup_at 升序)
2. 今天到期 (按 next_followup_at 升序)
3. 即将跟进 (按 next_followup_at 升序)

**业务规则：**
- 自动排除「已报名」和「无效」状态的线索
- 按 lead_id 去重（每个客户取最早的下次跟进时间）
- 最多返回 30 条
- counselor 只能看到自己的客户；admin/manager 可查看全部

### 1.2 next_followup_at 字段

`next_followup_at` 字段自 v0.1.0 起已存在于 `lead_followups` 表。本次无需数据库迁移。后端 Model、Schema、前端表单均已支持该字段。

## 4. API 变化

### 4.1 `GET /api/v1/dashboard/today-followups` — 响应增强

**新增返回字段：**

```json
{
  "lead_id": 1,
  "lead_name": "张三",
  "phone": "13800000001",
  "status": "following",
  "intention_level": "high",
  "next_followup_at": "2026-07-07 17:26:16",
  "owner_id": 1,
  "intended_course_name": "AI智能应用开发工程师",   // 新增
  "latest_followup_content": "电话沟通...",            // 新增
  "followup_priority": "overdue"                      // 新增 (overdue|today|upcoming)
}
```

**行为变化：**
- 之前：仅返回 today + overdue（≤ 今天 23:59:59），limit 20
- 现在：返回 overdue + today + upcoming（≤ 今天+3天 23:59:59），limit 30
- 之前：未过滤 enrolled/invalid 状态
- 现在：排除 enrolled 和 invalid 状态

### 4.2 其他 API — 无变化

`GET /api/v1/dashboard/summary` 的 `pending_followups` 字段保持原有语义（仅统计逾期+今天，不包含 upcoming）。

## 6. 生产部署步骤

### 前置检查

```bash
# 1. 确认当前版本
git log --oneline -3

# 2. 确认数据库备份存在
ls -la /opt/jiuwei-crm/backend/data/jiuwei_crm.db
```

### 部署

```bash
# 3. 拉取最新代码
cd /opt/jiuwei-crm
git pull origin main

# 4. 构建新镜像
docker compose build backend frontend

# 5. 滚动更新（不影响 nginx）
docker compose up -d backend frontend

# 6. 验证服务健康
curl -sk https://localhost/health
```

### 验证

```bash

TOKEN=$(curl -sk -X POST https://localhost/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"YOUR_PASSWORD"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['access_token'])")

# 测试今日待跟进 API
curl -sk https://localhost/api/v1/dashboard/today-followups \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool | head -20
```

- [ ] 返回数据包含 `intended_course_name`, `latest_followup_content`, `followup_priority` 字段
- [ ] 数据按优先级排序（overdue → today → upcoming）
- [ ] 登录 Dashboard 页面，看到增强的待跟进表格
- [ ] 已逾期行有红色标识
