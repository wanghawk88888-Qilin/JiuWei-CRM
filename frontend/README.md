# Frontend - JiuWei CRM

Next.js frontend for the JiuWei CRM system.

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- App Router

## Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Environment Variables

Copy `.env.example` to `.env.local` and adjust as needed:

- `NEXT_PUBLIC_API_BASE_URL` - Backend API base URL
